# Plan Discovery Questions

A **pool**, not a script. Read the Story, its requirements, any Design and the relevant code and tests first; ask only what remains (`../../../shared/interview.md`).

- **Scope:** plan this Story alone or a group? Anything explicitly out of this plan?
- **Order and risk:** which part is riskiest and should come first? Any dependency on other Stories or teams?
- **Conventions:** the code base does X for similar work; follow that, or diverge on purpose?
- **Verification:** what command runs the tests here, and are there checks that can only be done manually?
- **Constraints:** compatibility, release timing, review process, files that must not change?
- **Unknowns:** what could I not determine from the repository (missing tool, no access, unclear behavior), and who can answer?
